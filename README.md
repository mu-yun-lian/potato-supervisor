# 土豆监督员 Android · v0.3.1

[下载 v0.3.1 APK](https://github.com/mu-yun-lian/potato-supervisor/releases/tag/v0.3.1) · Android 8.0 及以上 · 无账号、无广告、离线运行

打开你选定的分心应用时，土豆地雷出现提醒。接受搜资料或休息理由后暂时放行，到点追问；次数用完按约定返回桌面。Kotlin 原生、离线运行、无需账号。

1. 设置目标、任务和监督应用，保存。
2. 阅读无障碍用途说明，在安卓设置手动启用“土豆监督员 · 应用提醒”。侧载限制见应用信息中的受限设置。
3. 设置中可开启动作音效、调整音量并试听；首页不再提供不扣额度的测试模式。
4. 点击“开始学习”，确认约定。默认每段两分钟、每轮三段，共六分钟；冷却二十分钟，之后可开始新一轮。
5. “单次放行 / 提醒间隔”按秒填写，范围 1–300 秒，最长五分钟。进入应用时仍立即提醒，不是等两分钟才首次出现。
6. “学习记录”填写实际完成的内容和可选分钟数，可补记、修改、删除；不推测实际学习时长。

普通切走和锁屏保留余额，回来先提醒，不赠送新的额度。多个目标共用次数与余额。每轮额度不是整场总上限；冷却到期会开始新一轮。监督已确认的前台使用，不读取页面内容，不判断理由真假。

三档语气：温和、讽刺、狠话。狠话含粗口和羞辱式反问，需本人主动选择；没有证明这一档比其他语气更能改善学习。拒绝默认用“考不上”等无依据结果判断。

界面采用花园配色、分组任务与设置、学习日志。角色包含出场、呼吸眨眼、点击弹跳、发红摇晃和短暂爆炸。支持减少动画，系统动画关闭或省电也会停止持续动作。

普通应用不能杀掉第三方进程。退出通过 HOME 返回桌面和冷却重入拦截实现，不能保证停止后台音频。爆炸期间覆盖层已经阻止操作；末次耗尽或冷却重入展示约 0.9 秒特效，再校验会话及动作后返回桌面。用户结束、切走或撤权会取消延迟动作。

| 模块 | 职责 |
|---|---|
| rules/Rules.kt | 唯一监督规则、确认前台计时、额度与冷却 |
| rules/StudyJournal.kt | 手动学习记录校验、按日更新、连续打卡 |
| storage/Repository.kt | 会话事务保存、旧版迁移 |
| storage/JournalRepository.kt | 独立日记存储、版本校验，异常不静默覆盖 |
| overlay/ | 提醒覆盖层、位图动作与退出提示 |
| ui/ | 花园首页、分组设置、日历与日记 |
| content/Dialogue.kt | 本地台词、稳定 ID 和变量替换 |

v0.1 数据迁移：旧版默认五分钟设置改为两分钟，若其总量仍是十五分钟则改为六分钟。旧版其他超长设置上限调整至五分钟。已开始且不超过五分钟的旧约定保留；旧约定超过新上限则结束并保留统计，重新开始使用新设置。学习打卡不会清除旧会话。

## v0.3.0 新增

- 修正键盘出现时目标应用仍可确认却停止计时的问题；通知遮挡与无法确认的分屏仍暂停。
- 设置里的语气、动效、震动、音效保存后立即生效，额度规则下次生效。
- 四种短音，默认关闭。设置 → 土豆的脾气 → 动作音效，可调音量并试听。静音、振动、勿扰、通话、锁屏停声。
- 学习记录支持导出/导入 JSON，冲突默认保留本机日期；允许明确覆盖。无需账号或存储权限。
- 结束本次监督后可选记录已完成/部分完成/未开始，未开始不计打卡。
- 设置 → 查看/添加提醒语录：257 条内置语录，可加 200 条自写语录；同场景语气轮完再重复，重启保留历史。

GitHub APK 为关闭调试标记的试用包，沿用本机原测试证书，可在原测试包上覆盖安装保留数据；更新后可导出学习记录。备份不包含自写语录/设置。完整验收范围及限制见 TEST_REPORT.md，v0.2.0 历史报告见 docs/TEST_REPORT-0.2.0.md。
