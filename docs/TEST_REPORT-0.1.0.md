## 失败与修正记录

- 首次纯包名事件路线：通知栏恢复与旋转失败。改为当前窗口元数据查询，扩大权限声明并在授权／隐私说明披露；代码不读取节点、正文或截图。
- 横屏测试最初没有滚动，找不到屏外按钮；加入实际滚动与点击检验后通过，没有放宽 prompt 连续性断言。
- 十秒解除文案最初依赖规则状态更新，静止提醒页不刷新；补充仅在覆盖层显示时运行的时钟刷新后通过。
- 十二秒冷却不足以容纳三个自动化重入动作，测试可能在正常到期后读到清零结果。该测试改为三十秒，规则未延长正式二十分钟冷却。
- 测试框架默认抑制其他无障碍服务、强制停止应用导致连接失效；测试显式保留并重新连接服务。此设置只属于隔离测试工具，不在产品内自动授权。
