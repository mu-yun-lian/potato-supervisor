# v0.3.2 横屏诊断与修复 · 2026-10-06

已确认一处代码缺陷，不把它等同于用户真实手机上的唯一原因。当前没有手机型号、安卓版本、游戏名称或真实设备日志。

原服务从窗口状态事件保存“编号→应用”，随后立即用当下窗口列表 retainAll。若事件先到、列表更新稍后到，新窗口身份会被删除；后续轮询列表无法重新取得应用包名，于是维持 UNKNOWN，暂停提醒与使用计时。将原缓存行为原样抽成 WindowPackages，使用“旧窗口列表、新窗口事件、新窗口列表”的顺序测试复现。新增最初 4 项测试中 2 项失败：该丢记录序列及新增的待确认身份过期要求；修复后新增 6 项和原 36 项全部通过。

修复只保留待核对的新事件最多 1.5 秒、最多 32 条；只有当前可见窗口可用于判断，已核对且消失的身份删除，过期身份不使用。补充接收 TYPE_WINDOW_CONTENT_CHANGED，只读取包名和窗口编号补齐缺失身份；已有身份不处理这类事件，不访问正文、事件源、根节点或截图。无包名的窗口状态事件仍会重新核对窗口。系统接管交互、多个应用窗口、未知或锁屏仍暂停，没有将未知窗口猜成游戏。

首页显示最近一次识别暂停的概括原因，保留在当前进程内，不保存应用活动历史，不进日记或备份。覆盖更新的签名与旧包一致。
