# iOS 原型数据说明

本说明对应 0.1.0 源码，不代表已完成 App Store 隐私审核。

* 无本项目账号、服务器、广告、分析 SDK、远程语料或自动上传。源码没有实现网络请求。
* 学习目标、任务、寄语、设置、授权后的不透明应用 token 和当前监督状态存放于主应用与扩展共用的 App Group。系统提供应用选择器；源码不尝试解码 token 为第三方应用身份，不读取第三方聊天、屏幕文字或视频内容。
* 学习内容与用户填写的分钟数存放于主应用 Documents。记录属于自报内容，不等于已验证的实际学习时间。屏幕使用门槛回调只保存计数，不收集逐应用明细历史。
* 用户点击分享时会生成一个临时 JSON 文件，再由系统分享面板交给用户指定的接收方；没有自动同步。系统设备备份属于用户的系统设置，不能从“没有本项目服务器”推导为系统从不备份。
* 可选通知仅用于提示回到主应用，不需要通知权限即可手动申请使用。声音只在主应用前台播放，使用 ambient 类别，遵循系统静音行为，不绕过专注模式。
* 使用包含休眠时间的单调时钟核对时段流逝，时钟信号仅保留在本地监督状态；隐私清单声明 System Boot Time 的 `35F9.1` 用途。不发送计时信号，也不用于指纹识别。
* 主动结束会清除本应用的 Managed Settings store 并停止本项目监测，保留学习记录；撤销屏幕使用时间授权后需要重新选择应用。individual 模式允许撤销授权及删除应用。
* 共享状态使用跨进程文件锁与原子写入。状态及日记使用首次解锁后可访问的文件保护，以便锁屏期间扩展读写；这不是端到端加密或不可篡改保证。

正式分发前需要根据最终构建、系统 SDK 和实际采集行为重新核对隐私清单与 App Store 答题，不能用此说明替代审核材料。
