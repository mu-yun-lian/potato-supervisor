# 土豆监督员 · iOS 源码原型 0.1.0

**状态：主应用与三个扩展已通过云端 Xcode 编译，iPhone 模拟器执行 12 个 XCTest 全部通过；尚未真机授权与拦截验证。已生成未签名 iPhone 设备版 IPA，普通 iPhone 不能直接安装，不是可上架版本。**

这是一版独立的原生 iPhone 应用，使用 SwiftUI 和 Apple 屏幕使用时间框架。保留本地学习约定、土豆语录、短暂使用额度、冷却和每天学习记录，不需要本项目账号、服务器或大模型。

## 必须先理解的差异

* iOS 系统拦截页使用静态图文。跨应用土豆动画、闪烁和爆炸声音没有照搬；动画与音效在本应用内运行。
* 一段放行期间，重新打开目标应用不会再弹一次土豆提醒；系统报告使用量达到门槛后才恢复屏蔽。多个选定应用共享本段额度。
* 15 分钟是监测窗口的最短长度，不是使用额度的最短长度。原型设为 15 分钟放行窗口，内部门槛可为 1–5 分钟；窗口结束收回放行，未确认的剩余量不退款。页面显示“已发放额度”，没有伪造秒级剩余余额。
* 系统回调不是硬实时承诺。短额度、窗口到期和横屏游戏的实际行为必须在 iPhone 验证。
* individual 授权可撤销，应用可删除，也可以主动结束本次监督；不是不可绕过的强制管控。
* iOS 26.5 起可通过系统拦截按钮返回本应用；旧系统需要用户手动打开，允许通知时有可选通知入口。通知拒绝不阻止手动申请。

## 打开源码

云端实测：Xcode 26.5 / iOS Simulator SDK 26.5，完整结果见 [测试报告](docs/TEST_REPORT.md)。

解压后打开 `PotatoSupervisor.xcodeproj`，共享方案名为 `PotatoSupervisor`。工程已生成，打开时不需要 Python、CocoaPods 或第三方 Swift 包。

最低运行版本为 **iOS 17.4**。编译必须使用含 **iOS 26.5 或更新 SDK** 的 Xcode，因为源码引用了 26.5 新增的可用性保护分支；仅有旧 SDK 时，`#available` 不会使编译器认识新枚举值。

在 `Config/Project.xcconfig` 填入自己的 Bundle ID、App Group 与 Team ID；后续签名及验证步骤见 [BUILD.md](BUILD.md)。目前标识是占位符，没有包含账户、证书或私钥。

## 目录

* `App/`：主应用界面、授权协调、学习记录和前台音效。
* `Shared/`：规则、共享持久化、系统监测协调和语录。
* `Extensions/`：Device Activity Monitor、Shield Configuration、Shield Action 三个扩展。
* `Tests/`：9 个规则和 3 个资源 XCTest。
* `Config/`：标识配置、各目标 Info.plist、能力声明和隐私清单。
* `Resources/`：位图、语录、声音与素材声明。
* `docs/`：适配设计、检查报告、真机验收清单、声音溯源。
* `scripts/generate_project.py`：可选工程再生成工具，使用 Python 标准库；修改生成的目标配置前请注意再生成会覆盖工程与 Info.plist。

## 尚未移植的部分

没有实现 Android 的每次重入提醒、悬浮动画与强制返回桌面；没有实现安卓版完整提醒模式、逐句屏蔽、自定义语录、历史去重策略、记录导入及统计图。首版只选择具体应用，不选择应用分类或网站。iPad 布局和平台同步也未制作。原型与 Android 没有自动共享数据。
