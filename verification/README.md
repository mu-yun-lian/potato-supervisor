- `fresh-build.txt`：交付 Build.ps1 在独立解压目录的构建结果，使用缓存公开依赖。
- `lint.txt`：对应静态检查结果，0 错误／12 警告。
- `signature.txt`、`permissions.txt`：最终 APK 的签名校验与普通权限列表。
- `source-match.txt`：最终生产源码与干净构建目录逐文件校验；仅报告、截图、验证记录和测试工具随后补充。

构建文本中的本机工作目录统一替换为 `<WORKSPACE>`，其他执行结论与警告不改写。测试数据与本机路径替换不代表真实用户活动；没有收集手机使用历史。源码 ZIP 不包含 build／Gradle 缓存、本机 local.properties 或签名私钥。
